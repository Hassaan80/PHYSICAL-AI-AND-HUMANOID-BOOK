# PHYSICAL-AI-AI-AND-HUMANOID-BOOK

## RAG Ingestion Pipeline

This project includes a Python-based pipeline for ingesting content from the Docusaurus book into a Qdrant vector database. This pipeline automates the process of fetching book content, chunking it, generating semantic embeddings using Cohere, and storing them for Retrieval-Augmented Generation (RAG) purposes.

For detailed setup and usage instructions, please refer to the [Quickstart Guide](specs/3-rag-ingestion-pipeline/quickstart.md).
